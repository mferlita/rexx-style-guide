# Contributing

## Propose a new guideline or a change to an existing guideline
1. Open an issue with the guideline-proposal or guideline-change label
2. Include the rule, a good/bad example, and the rationale

## Submit a PR
1. Open a pull request against "main"
2. Keep the same format as existing rules
3. Link to the corresponding issue

## Resolving disagreements
* The maintainer will make the final decision
